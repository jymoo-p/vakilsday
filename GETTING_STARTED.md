# Getting Started with VakilsDay

## What is VakilsDay?

VakilsDay is a multi-tenant SaaS platform for Indian litigation lawyers. Each law firm creates their own workspace with complete data isolation.

---

## Quick Setup (5 minutes)

### Prerequisites
- Node.js 18+ installed
- Google account for OAuth

### Step 1: Run Multi-Tenant Setup

```bash
./setup-multi-tenant.sh
```

This will:
- Generate Prisma client
- Create database migration (adds Organizations)
- Set up multi-tenant architecture

### Step 2: Configure Google OAuth

You need Google OAuth credentials for sign-in:

1. Go to: https://console.cloud.google.com/
2. Create a new project: "VakilsDay Dev"
3. Enable APIs:
   - Google+ API
   - Google Calendar API
4. Create OAuth 2.0 Client ID:
   - Type: Web application
   - Redirect URI: `http://localhost:3000/api/auth/callback/google`
5. Copy credentials to `.env`:

```env
GOOGLE_CLIENT_ID="your-actual-client-id.apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET="GOCSPX-your-actual-secret"
```

**Detailed guide:** See `GOOGLE_OAUTH_SETUP.md`

### Step 3: Generate NextAuth Secret

```bash
openssl rand -base64 32
```

Add to `.env`:
```env
NEXTAUTH_SECRET="paste-generated-secret-here"
```

### Step 4: Start Development Server

```bash
# Start Postgres (if not running)
npx prisma dev

# Start Next.js
npm run dev
```

### Step 5: Create Your Law Firm

1. Open: http://localhost:3000
2. You'll see the landing page
3. Click "Sign In with Google"
4. Authenticate with Google
5. Fill the onboarding form:
   - Firm Name: "Your Law Firm"
   - Your Name: (auto-filled)
6. Submit
7. You're now an ADMIN of your workspace!

## Database Schema

### New Model: Organization
```prisma
model Organization {
  id    String @id @default(cuid())
  name  String              # "Shah & Associates"
  slug  String @unique      # "shah-associates"
  
  users User[]
  cases Case[]
}
```

### Updated Models
- **User:** Now has `organizationId`
- **Case:** Now has `organizationId` (data isolation)

## Environment Variables Checklist

Your `.env` should have:

```env
# Database (auto-generated by prisma dev)
DATABASE_URL="prisma+postgres://localhost:51213/..."

# NextAuth
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="<run: openssl rand -base64 32>"

# Google OAuth (from console.cloud.google.com)
GOOGLE_CLIENT_ID="<your-client-id>.apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET="GOCSPX-<your-secret>"

# Supabase (optional for now)
NEXT_PUBLIC_SUPABASE_URL="https://your-project.supabase.co"
NEXT_PUBLIC_SUPABASE_ANON_KEY="your-key"
SUPABASE_SERVICE_ROLE_KEY="your-key"
```

## Common Issues

### Issue: "Cannot find module @prisma/client"
**Solution:**
```bash
npx prisma generate
npm run dev
```

### Issue: OAuth error "invalid_client"
**Solution:** Check `.env` has real Google credentials, not placeholders
See: `FIX_OAUTH_ERROR.md`

### Issue: Stuck on onboarding after submitting
**Solution:** 
1. Check browser console (F12) for errors
2. Check server terminal for API errors
3. Verify database connection

### Issue: TypeScript errors about organizationId
**Solution:** Regenerate Prisma client
```bash
npx prisma generate
```
